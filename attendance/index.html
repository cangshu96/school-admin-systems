🚀 首次配置（仅教务处需要操作一次）

1
注册 Supabase 免费账号：
打开 supabase.com → 点击 Start your project → 用 GitHub 或邮箱注册
2
点击 New Project，填写项目名称（如 school-attendance），选择区域 East Asia (Singapore)，设置数据库密码（记住它），点击 Create
3
等待项目创建完成（约1-2分钟），然后点击左侧 SQL Editor → New query
将下方 SQL 脚本复制粘贴进去，点击 Run 执行
-- 级部考勤系统数据库初始化 -- 1. 班级表 CREATE TABLE IF NOT EXISTS classes ( id TEXT PRIMARY KEY, name TEXT NOT NULL, students JSONB DEFAULT '[]'::jsonb, sort_order INT DEFAULT 0, created_at TIMESTAMPTZ DEFAULT NOW() ); -- 2. 考勤表（每天每班一条记录） CREATE TABLE IF NOT EXISTS attendance ( date DATE NOT NULL, class_id TEXT NOT NULL REFERENCES classes(id) ON DELETE CASCADE, records JSONB DEFAULT '{}'::jsonb, updated_at TIMESTAMPTZ DEFAULT NOW(), PRIMARY KEY (date, class_id) ); -- 3. 启用行级安全 ALTER TABLE classes ENABLE ROW LEVEL SECURITY; ALTER TABLE attendance ENABLE ROW LEVEL SECURITY; -- 4. 允许读写 CREATE POLICY "classes_all" ON classes FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "attendance_all" ON attendance FOR ALL USING (true) WITH CHECK (true); -- 5. 自动更新时间触发器 CREATE OR REPLACE FUNCTION update_modified_column() RETURNS TRIGGER AS $$ BEGIN NEW.updated_at = NOW(); RETURN NEW; END; $$ LANGUAGE plpgsql; CREATE TRIGGER trigger_classes_updated BEFORE UPDATE ON classes FOR EACH ROW EXECUTE FUNCTION update_modified_column(); CREATE TRIGGER trigger_attendance_updated BEFORE UPDATE ON attendance FOR EACH ROW EXECUTE FUNCTION update_modified_column(); -- 6. 示例班级 INSERT INTO classes (id, name, students, sort_order) VALUES ('c1','1班','[]',0), ('c2','2班','[]',1), ('c3','3班','[]',2) ON CONFLICT (id) DO NOTHING;
4
点击左侧 Project Settings（齿轮图标）→ API
找到以下两项并复制：
  • Project URL — 形如 https://xxxx.supabase.co
  • anon public key — 一长串 eyJ 开头的字符串
5
